## 2024-05-18 - Declarative Accessibility Attributes in React
**Learning:** Found an anti-pattern in the application where accessibility attributes (`aria-label`) were added to elements (like `<select>`, inputs, and icon-only buttons) using imperative DOM manipulation via `useEffect` (e.g., `document.querySelectorAll('select').forEach(...)`). This approach is fragile in React because elements are re-rendered and their nodes re-created, causing the dynamically attached attributes to be lost or leading to race conditions.
**Action:** Always write accessibility attributes declaratively in the JSX for React applications. Ensure that elements like form fields and icon-only buttons have their appropriate `aria-label`s directly in the component markup, which maintains accessibility robustly across re-renders.
