## 2026-09-04 - Memoization in React with long lists\n**Learning:** Un-memoized mapping of large string values to JSX elements (e.g. rendering large API response JSON bodies line by line) and filtering over large arrays on every render (e.g. searching collections) blocks the main thread in React during keystrokes (like typing in URL or Body).\n**Action:** Use `useMemo` for computationally heavy render operations, such as filtering a list or mapping large text strings into JSX elements, to avoid unnecessary work when unrelated state (like input value) changes.
