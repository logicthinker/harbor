## 2026-09-04 - Refactored ARIA Labels to React Native\n**Learning:** Found a pattern where `aria-label` attributes were being manually injected into DOM elements via a `useEffect` hook instead of being declaratively set in JSX. This was an anti-pattern and was buggy (it would incorrectly apply labels to unrelated dropdowns).\n**Action:** Replaced the DOM-mutating `useEffect` with proper declarative `aria-label` props directly on the JSX elements (selects, inputs, and icon buttons). This ensures labels are present on initial render, respects React's lifecycle, and prevents bugs from global DOM querying.
